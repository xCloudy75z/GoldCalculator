# حاسبة الذهب

تطبيق ويب عربي خفيف لتقدير سعر شراء الذهب في الإمارات. يعمل بالكامل داخل المتصفح، ويحفظ آخر القيم على الجهاز، ويمكن تثبيته على شاشة iPhone الرئيسية واستخدامه دون اتصال بعد أول تحميل ناجح.

## المزايا

- واجهة عربية بالكامل واتجاه من اليمين إلى اليسار.
- حساب فوري دون زر منفصل.
- دعم عيارات 18 و21 و22 و24 دون تحويل تلقائي بين العيارات.
- عرض سعر الذهب والمصنعية والضريبة والإجماليين كلٌّ على حدة.
- حفظ آخر القيم محلياً وإمكانية إعادة تعيينها.
- تطبيق PWA ثابت دون خادم أو حساب أو خدمة خارجية.
- ملفات محلية بالكامل للعمل دون اتصال بعد تخزينها مؤقتاً.

## طريقة الحساب

```text
سعر الذهب = سعر جرام الذهب × الوزن
إجمالي المصنعية = مصنعية الجرام × الوزن
الإجمالي بدون الضريبة = سعر الذهب + إجمالي المصنعية
الضريبة = الإجمالي بدون الضريبة × 5%
الإجمالي شامل الضريبة = الإجمالي بدون الضريبة + الضريبة
```

مثال التحقق المضمّن في الاختبارات: سعر الجرام `375` درهماً، والمصنعية `25` درهماً، والوزن `10` جرامات. الناتج هو `4,000.00 د.إ` قبل الضريبة و`4,200.00 د.إ` شامل الضريبة.

## التشغيل محلياً

يتطلب اختبار عامل الخدمة خادماً محلياً بدلاً من فتح `index.html` مباشرة:

```powershell
python -m http.server 4173
```

ثم افتح `http://localhost:4173/`. لا توجد خطوة بناء أو حزم مطلوبة للتطبيق نفسه.

لتشغيل الاختبارات الآلية:

```powershell
npm test
```

تتحقق الاختبارات من المعادلات، والقيم العشرية والصفرية والفارغة وغير الصالحة، ومنع النتائج غير المحدودة، وتنسيق الدرهم، وحفظ الحالة وإعادة التعيين، وبيان PWA، وأبعاد الأيقونات، ومسارات التخزين المؤقت، والتنقل دون اتصال.

## النشر المجاني على GitHub Pages

1. أنشئ مستودعاً جديداً في GitHub وارفع جميع ملفات هذا المجلد إلى الفرع الرئيسي.
2. افتح المستودع في GitHub ثم انتقل إلى **Settings → Pages**.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح الرابط الذي يكون عادة بالشكل التالي:

   ```text
   https://USERNAME.github.io/REPOSITORY/
   ```

كل مسارات التطبيق نسبية، لذلك يعمل داخل مسار المستودع ولا يشترط النشر في جذر النطاق.

## التثبيت على iPhone

1. افتح رابط GitHub Pages المنشور باستخدام Safari.
2. انتظر حتى يكتمل التحميل الأول مرة واحدة مع وجود اتصال بالإنترنت.
3. اضغط زر المشاركة في Safari.
4. اختر **إضافة إلى الشاشة الرئيسية**.
5. تأكد من الاسم `حاسبة الذهب` ثم اضغط **إضافة**.
6. افتح التطبيق من الأيقونة الجديدة على الشاشة الرئيسية.

يحدد iOS شكل شاشة التثبيت وبعض سلوك واجهة التطبيق المثبت وفق إصدار النظام وSafari.

## اختبار العمل دون اتصال

1. افتح التطبيق المنشور مرة واحدة واترك الصفحة تكتمل في Safari.
2. أغلق التطبيق وافتحه مرة أخرى للتأكد من تفعيل عامل الخدمة.
3. فعّل **وضع الطيران** على iPhone.
4. افتح التطبيق من الشاشة الرئيسية أو أعد تحميله في Safari.
5. تأكد من ظهور الحاسبة ومن إمكانية إدخال القيم وإجراء الحساب وإعادة التعيين.

إذا نُشرت نسخة جديدة، افتح التطبيق مرة واحدة مع الاتصال بالإنترنت حتى يتم تنزيل ملفات التخزين المؤقت الجديدة.

## بنية المشروع

```text
index.html              الواجهة العربية
style.css               التصميم المتجاوب مع iPhone
app.js                   الحساب والحالة المحلية والتفاعل
manifest.webmanifest    بيانات تثبيت التطبيق
service-worker.js       التخزين المؤقت والعمل دون اتصال
icons/                  أيقونات PWA وApple
tests/                  اختبارات Node الآلية
```

## نطاق التحقق

تم تشغيل الاختبارات الآلية عبر `npm test` للتحقق من الحسابات والحالة وملفات PWA وسلوك التخزين المؤقت دون اتصال. لم يُختبر التثبيت فعلياً على جهاز iPhone، لذلك يجب إجراء خطوات iPhone أعلاه على الجهاز المستهدف قبل الاعتماد عليه في الاستخدام اليومي.
